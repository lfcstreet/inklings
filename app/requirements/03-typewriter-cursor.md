# Requirement 03 — Typewriter-Style Cursor

## Objective

Change the writing editor so that the text moves vertically underneath the
cursor, creating a typewriter-like writing experience.

The cursor should remain at approximately the same vertical position on the
screen while the user writes.

This requirement is ONLY about vertical cursor positioning.

Do not implement the line-hiding behavior yet.

---

## Current Behavior

The editor currently behaves like a normal Android text editor.

As the user moves down through the document, the cursor eventually moves
toward the bottom of the screen and the document scrolls normally.

Change this behavior so that the cursor remains approximately centered
vertically in the writing area.

---

## Required Behavior

The cursor should remain approximately in the vertical center of the
writing area.

For example:

```text
┌──────────────────────────────────────┐
│                                      │
│  previous text                       │
│  previous text                       │
│  previous text                       │
│                                      │
│  CURRENT LINE |                      │
│                                      │
